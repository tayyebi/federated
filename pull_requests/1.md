## Summary
This PR establishes the foundational scaffolding for the Federated project following test-first development methodology.

## Changes
- **LICENSE**: Added LGPL-3.0 license allowing proprietary applications while requiring modifications to the library be shared
- **TODO.md**: Project-wide task tracker with CI enforcement to keep it updated
- **docs/test_scenarios.md**: Comprehensive test scenario documentation
- **Test Framework**: Zero-dependency test framework in `include/federated/test/test.h`
- **Core Primitives**: Headers and implementations for Buffer, Error, Packet, Registry
- **Transport Layer**: Transport interface and initial implementations
- **Build System**: CMake configuration for libraries and tests
- **CI/CD**: GitHub workflow to validate TODO.md updates in PRs
- **Templates**: PR and issue templates to guide contributors
